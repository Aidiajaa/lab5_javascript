## H. Pertanyaan dan Tugas

### 1. Perbedaan Output dan Dialog
* **`console.log()`**: Menampilkan pesan atau data pada panel Konsol Pengembang (*Developer Tools*) di browser, sehingga tidak mengganggu tampilan halaman web dan sangat berguna untuk proses *debugging*.
* **`alert()`**: Menampilkan pesan peringatan dalam bentuk kotak dialog pop-up yang menghentikan alur sementara sampai pengguna menekan tombol OK.
* **`prompt()`**: Menampilkan kotak dialog input yang meminta masukan teks secara langsung dari pengguna.
* **`textContent` / `innerHTML`**: Digunakan untuk menampilkan atau mengubah konten elemen HTML di dalam halaman web. `textContent` hanya memproses teks polos, sedangkan `innerHTML` dapat memproses struktur dan tag HTML.

### 2. Perbedaan `let` dan `const`
* **`let`**: Digunakan untuk mendeklarasikan variabel yang nilainya dapat diubah kembali (*re-assign*) selama program berjalan.
  
  *Contoh:*
  ```javascript
  let nilai = 75;
  nilai = 80; // Nilai berhasil diubah
  ```

* **`const`**: Digunakan untuk mendeklarasikan variabel konstan yang nilainya tetap dan tidak bisa diubah ulang setelah diinisialisasi.
  
  *Contoh:*
  ```javascript
  const nama = "Rani";
  // nama = "Budi"; // Error: nilai variabel const tidak dapat diubah
  ```

### 3. Perbedaan Operator `==` dan `===`
* **`==` (Equality)**: Membandingkan dua nilai tanpa memeriksa tipe datanya, sehingga JavaScript akan melakukan konversi tipe data otomatis sebelum membandingkan.
* **`===` (Strict Equality)**: Membandingkan dua nilai beserta tipe datanya secara ketat tanpa konversi otomatis.

*Contoh:*
* `'5' == 5` bernilai `true` (string dipaksa menjadi angka).
* `'5' === 5` bernilai `false` (tipe string berbeda dengan tipe number).

### 4. Fungsi `if-else` dan `switch`
* **`if-else`**: Digunakan untuk mengevaluasi kondisi logis, rentang nilai (seperti `>`, `<`, `>=`), atau ekspresi boolean yang kompleks. Digunakan saat pengujian membutuhkan kondisi yang fleksibel.
* **`switch`**: Digunakan untuk memilih satu tindakan dari banyak pilihan berdasarkan pencocokan nilai pasti. Cocok digunakan saat pilihan bernilai tetap, seperti menu angka $1$ sampai $5$.

### 5. Fungsi Parameter dan Return
* **Parameter**: Berfungsi sebagai wadah variabel yang menerima masukan data saat fungsi dipanggil.
* **Return**: Berfungsi untuk mengembalikan hasil pemrosesan dari fungsi ke pemanggilnya agar nilai tersebut dapat disimpan dalam variabel atau dipakai kembali pada proses lain.

### 6. Cara `document.getElementById()` Memilih Elemen
`document.getElementById()` bekerja dengan cara memindai dokumen HTML dan mencari elemen yang memiliki atribut `id` sesuai dengan string yang dimasukkan. Setelah ketemu, fungsi ini mengembalikan referensi elemen tersebut berupa objek DOM agar isi teks, gaya CSS, atau perilakunya dapat diubah melalui JavaScript.

### 7. Script Validasi Form Nama dan Rentang Nilai
```javascript
function validasiForm(nama, nilai) {
    const angka = Number(nilai);

    // Validasi kolom nama tidak boleh kosong
    if (!nama || nama.trim() === "") {
        return "Error: Nama tidak boleh kosong!";
    }

    // Validasi nilai harus berupa angka dan berada pada rentang 0-100
    if (isNaN(angka) || angka < 0 || angka > 100 || nilai.trim() === "") {
        return "Error: Nilai harus berupa angka pada rentang 0 hingga 100!";
    }

    return "Validasi berhasil: Data siap diproses.";
}

// Contoh Pengujian
console.log(validasiForm("Rani", "85"));  // Validasi berhasil
console.log(validasiForm("", "85"));      // Error nama kosong
console.log(validasiForm("Rani", "150")); // Error nilai di luar rentang
```
